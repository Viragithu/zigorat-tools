# ابزارهای زیگورات

دو ابزار مستقل (بدون نیاز به کلود یا هیچ سروری):

- `zigorat-cover-maker.html` — کاورساز
- `zigorat-size-guide.html` — راهنمای سایز

`index.html` صفحهٔ شروعه. با `manifest.webmanifest` و `sw.js` روی گوشی نصب می‌شه و بدون اینترنت هم کار می‌کنه.

**به‌روزرسانی:** هر وقت یکی از فایل‌ها عوض شد، توی `sw.js` عدد `VERSION` رو یکی بیشتر کن (مثلاً `zig-v2`).

**داده‌ها:** محصول‌های راهنمای سایز و طرح‌های کاورساز فقط روی همون گوشی و مرورگر ذخیره می‌شن. از بخش «پشتیبان» راهنمای سایز فایل پشتیبان بگیر.

**فونت‌ها:** استعداد، وزیرمتن، لاله‌زار، ساحل، شبنم، Noto Kufi، Reem Kufi، El Messiri، Baloo Bhaijaan 2، Markazi، Aref Ruqaa، Jomhuria و Changa، همه با مجوز آزاد SIL OFL (فایل `FONTS-LICENSE-OFL.txt`).
